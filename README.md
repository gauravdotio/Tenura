# Tenura — Personal Loans, Credit Cards & EMI Amortization Dashboard

A modern personal finance dashboard designed to track active loans, credit card balances, recurring EMIs, and monthly expenses across multiple profiles.

## ✨ Features
- **Multi-Profile Support**: Switch between **Gaurav**, **Didi**, or combined **All (Household)** views.
- **Master Active Liabilities Table**: Credit cards, active loans, and converted EMI installments with live totals.
- **Interactive EMI Amortization Schedules**: Month-by-month payment checklists with live "Total Left" tracking.
- **Financial Analytics**: Cashflow outflow projections, liability share distribution, and debt burndown curve.
- **Daily Expense Ledger**: Category tagging and monthly budget limits.
- **Encrypted Local Storage & Backup**: Instant CSV/JSON export & restore.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```
